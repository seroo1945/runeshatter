# Runeshatter — official coming-soon landing page

Static, responsive English-language landing page. No backend, database or build tools required.

## Preview locally
Open `index.html` in a browser. Google Fonts require an internet connection; fallback fonts are provided.

## Publish on GitHub Pages
1. Create a **public** GitHub repository named `runeshatter`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, `main`, `/ (root)`, and Save.
5. The website should appear at `https://YOUR-USERNAME.github.io/runeshatter/` after deployment.
